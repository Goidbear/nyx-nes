# Nyx NES

A cycle-accurate NES emulator written from scratch in C++17.

## Known Limitations
- **Kirby's Adventure**: Graphics corrupted (MMC3 CHR-RAM jail-bar artifact).
- **Battletoads / Punch-Out**: Do not boot (need deeper cycle accuracy).
- **SMB3**: Minor green-cloud scroll glitch (playable).

## Controls
- Arrows: D-pad
- Z: A button
- X: B button
- Enter: Start
- F5/F7: Save/Load State

## Legal
No ROMs are included.
